# AltPane 0.4.17

## 中文

- 移除 0.4.16 中新增的 Codex bridge、AI 文字处理窗口、登录与状态检查入口、Ctrl+Alt+J 快捷键和相关配置。
- 窗口底色调深为中性灰：浅色主题为 #E8E8E8，深色主题为 #181818。切换器、设置及关于窗口使用一致底色，标题栏颜色同步更新。
- 保留原有窗口切换、搜索和文件对话框快速跳转功能。已有 Codex 登录凭据由 Codex 自身管理，本次移除不会修改凭据。
- 本地验证：347 项测试通过，Windows 目标编译通过。实际 Windows 桌面显示仍需实机确认。

## English

- Remove the Codex bridge, AI text window, login/status integration, Ctrl+Alt+J shortcut and associated configuration introduced in 0.4.16.
- Use slightly darker neutral gray window backgrounds: #E8E8E8 in the light theme and #181818 in the dark theme. Keep switcher, settings, About and native caption colors consistent.
- Preserve window switching, search and file-dialog quick jump. Existing Codex-managed credentials are not modified.
- Local validation: 347 tests passed and the Windows-target build succeeded. Desktop appearance still requires Windows validation.
